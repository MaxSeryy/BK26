# Каталог збереження моделей

У цей каталог експортуються локальні чекпоінти та фінальні натреновані ваги моделей:
- PyTorch state_dict (`.pth`, `.pt`)
- ONNX моделі (`.onnx`)
- OpenVINO IR файли (`.xml`, `.bin`)

## Примітка
Бінарні файли великих моделей ігноруються в системі контролю версій Git відповідно до налаштувань `.gitignore`.
