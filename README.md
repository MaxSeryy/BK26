# Практикум: Технології програмування систем штучного інтелекту

Репозиторій містить комплекс із п'яти наскрізних лабораторних робіт з дисципліни «Технології програмування систем штучного інтелекту». Проєкт охоплює повний життєвий цикл розробки та розгортання моделей комп'ютерного зору: від первинного збору й валідації датасету до тренування згорткових нейромереж, оптимізації інференсу та продакшн-розгортання.

---

## Структура репозиторію

Репозиторій структуровано згідно з модульною архітектурою практикуму:

```text
ai-programming-labs/
├── README.md                  # Загальний опис проєкту та інструкції з розгортання
├── requirements.txt           # Зафіксовані версії основних бібліотек
├── .gitignore                 # Виключення віртуального середовища, кешу, сирих датасетів і ваг
├── data/                      # Маніфести розбиття, метадані та описи датасетів
│   ├── dataset_split.json     # Результати стратифікованого розбиття (seed=13)
│   ├── stats_summary.json     # Агреговані статистичні метрики датасету
│   └── README.md              # Інструкція з отримання та генерації даних
├── lab01_data/                # Лабораторна робота №1: Підготовка та обробка даних
│   ├── generate_dataset.py    # Генератор синтетичного датасету з тестовими крайовими випадками
│   ├── pipeline.py            # Повний конвеєр верифікації, letterbox-масштабування та аугментації
│   ├── data_loader.py         # Відтворюваний пакетний завантажувач VisionDatasetLoader
│   ├── draw_flowchart.py      # Скрипт побудови блок-схеми обробки даних
│   ├── pipeline_flowchart.drawio # Векторний макет блок-схеми у форматі Draw.io
│   ├── figures/               # Графіки, гістограми та приклади аугментації
│   └── README.md              # Інструкція з виконання та запуску ЛР №1
├── lab02_cnn/                 # Лабораторна робота №2: Навчання згорткової нейромережі
├── lab03_computer_vision/     # Лабораторна робота №3: Комп'ютерний зір та детекція
├── lab04_deployment/          # Лабораторна робота №4: Розгортання моделі (ONNX / REST API)
├── lab05_optimization/        # Лабораторна робота №5: Профілювання та оптимізація (OpenVINO)
├── models/                    # Локальні та експортовані моделі (ваги ігноруються в Git)
├── reports/                   # Локальні звіти у форматі docx (ігноруються в Git)
```

## Встановлення та налаштування середовища

Для забезпечення повної ізоляції та стабільності версій робота виконується виключно у віртуальному середовищі Python (`venv`).

### 1. Створення та активація віртуального середовища

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Встановлення залежностей

Усі необхідні бібліотеки зафіксовано у файлі `requirements.txt`:
```powershell
pip install -r requirements.txt
```

## Робота з даними

Згідно з інженерними вимогами, сирі набори зображень та важкі бінарні ваги навчених моделей не включаються безпосередньо до Git-репозиторію. Усі каталоги сирих даних включені до `.gitignore`.

### Спосіб отримання / генерації датасету:
Для відтворення датасету за варіантом 13 (класи `drone`, `car`, `pedestrian`) запустіть генератор:
```powershell
python lab01_data/generate_dataset.py
```
Скрипт створить локальну директорію `data/dataset` із 300 валідними зразками різного розширення та 2 тестовими пошкодженими файлами для перевірки надійності модуля очищення даних.

## Запуск конвеєра Лабораторної роботи №1

1. **Аналіз датасету, фільтрація дефектів, розбиття та аугментація:**
   ```powershell
   python lab01_data/pipeline.py
   ```
   В результаті виконання:
   - Фільтруються биті файли (звіт зберігається у `data/stats_summary.json`);
   - Формується стратифіковане розбиття 70/15/15 із фіксованим `seed = 13` (`data/dataset_split.json`);
   - Генеруються всі візуалізації в `lab01_data/figures/`.

2. **Перевірка модуля пакетного завантаження даних для ЛР №2:**
   ```powershell
   python lab01_data/data_loader.py
   ```

3. **Оформлений звіт:**
   Звіт з детальним описом експериментів, аналізом результатів, графіками та відповідями на контрольні запитання сформовано у файлі `reports/Report_Lab1.docx`.
