# Лабораторна робота №3: Задачі комп'ютерного зору та глибокого навчання

## Мета
Дослідження моделей розпізнавання та локалізації об'єктів (детекція або сегментація) у задачах комп'ютерного зору.

## Заплановані завдання
1. Підготовка анотацій для детекції об'єктів.
2. Адаптація претренованої моделі (Transfer Learning / Fine-tuning).
3. Оцінка метрик якості локалізації (mAP, IoU).
4. Збереження результатів інференсу на тестових зображеннях.
