# Дані та метадані датасетів

Каталог призначений для збереження метаданих, маніфестів розбиття та статистичних звітів підготовки даних.

## Вміст:
- `dataset_split.json` — маніфест стратифікованого розбиття на train (70%), validation (15%) та test (15%) з фіксованим seed=13.
- `stats_summary.json` — агреговані розміри зображень, розподіл за класами та перелік відфільтрованих дефектних файлів.

## Сирі зображення
Відповідно до інженерних вимог практики, великі набори зображень не комітяться у Git-репозиторій. Директорія `data/dataset/` додана до `.gitignore`.

Для генерації локального набору зображень виконайте:
```bash
python lab01_data/generate_dataset.py
```
