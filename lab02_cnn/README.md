# Лабораторна робота №2: Розробка та навчання згорткової нейронної мережі

## Мета роботи
Реалізація архітектури згорткової нейронної мережі (CNN), побудова повноцінного циклу навчання та валідації з механізмом збереження найкращих ваг (чекпоінтів), оцінка якості класифікації на тестовій вибірці та аналіз стійкості до спотворень.

---

## Інструкція з відтворення

### 1. Підготовка даних (якщо не згенеровано раніше)
Для відновлення структури датасету та маніфесту розбиття з ЛР №1:
```powershell
python lab01_data/generate_dataset.py
python lab01_data/pipeline.py
```
Зображення зберігаються у `data/dataset/`, а розбиття на вибірки — у `data/dataset_split.json`. Великі масиви зображень не зберігаються в репозиторії відповідно до `.gitignore`.

### 2. Запуск навчання та тестування
Запуск тренування моделі, побудова графіків та оцінювання на тестовій вибірці:
```powershell
python -m lab02_cnn.train
```

В процесі виконання:
1. Завантажуються батчі даних із нормалізацією ImageNet та аугментацією (Train: 210, Val: 45, Test: 45).
2. Навчається модель `SimpleCNN` протягом 20 епох з оптимізатором Adam.
3. Ваги найкращої моделі за валідаційною точністю автоматично зберігаються у `models/best_cnn_model.pt`.
4. Генеруються та зберігаються графіки кривих навчання (`figures/training_curves.png`), матриця помилок (`figures/confusion_matrix.png`) та зразки прогнозів (`figures/predictions_sample.png`).
5. Результати метрик записуються у `lab02_cnn/test_metrics.json`.

## Архітектура моделі SimpleCNN
- **Вхід**: тензор розмірності $(N, 3, 64, 64)$.
- **Згортковий блок 1**: `Conv2d(3 -> 32, k=3, p=1)` -> `BatchNorm2d(32)` -> `ReLU` -> `MaxPool2d(2, 2)`.
- **Згортковий блок 2**: `Conv2d(32 -> 64, k=3, p=1)` -> `BatchNorm2d(64)` -> `ReLU` -> `MaxPool2d(2, 2)`.
- **Згортковий блок 3**: `Conv2d(64 -> 128, k=3, p=1)` -> `BatchNorm2d(128)` -> `ReLU` -> `MaxPool2d(2, 2)`.
- **Пулінг та класифікатор**: `AdaptiveAvgPool2d((4, 4))` -> `Flatten` -> `Dropout(0.4)` -> `Linear(2048 -> 128)` -> `ReLU` -> `Dropout(0.3)` -> `Linear(128 -> 3)`.
- **Кількість параметрів**: 356,131.
