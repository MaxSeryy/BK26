# Лабораторна робота №2: Навчання згорткової нейромережі (CNN)

## Мета
Реалізація, навчання та дослідження згорткової архітектури нейронної мережі для задачі багатокласової класифікації на підготовлених даних з ЛР №1.

## Заплановані завдання
1. Побудова CNN архітектури (PyTorch) для класифікації 3 класів.
2. Інтеграція `VisionDatasetLoader` з ЛР №1.
3. Навчання з валідацією, побудова графіків Loss та Accuracy.
4. Оцінка матриці помилок (Confusion Matrix) та метрик Precision/Recall.
5. Експорт збережених ваг у директорію `models/`.
