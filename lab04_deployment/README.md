# Лабораторна робота №4: Розгортання та інтеграція моделі

## Мета
Експорт натренованої моделі у платформонезалежний формат (ONNX) та побудова мікросервісу для інференсу в реальному часі.

## Заплановані завдання
1. Експорт PyTorch ваг у формат ONNX.
2. Верифікація точності та порівняння швидкості виконання у ONNX Runtime.
3. Розробка REST API сервісу (FastAPI / Flask) для обробки зображень.
4. Контейнеризація застосунку (Dockerfile).
