# Лабораторна робота №4: Експорт та розгортання моделі у ONNX Runtime і OpenVINO

## Мета роботи
Опанувати перенесення навченої згорткової моделі з фреймворку PyTorch у відкритий формат обчислювального графа ONNX, перевірку коректності й чисельної еквівалентності виходів, розгортання автономного інференсу у середовищах ONNX Runtime та Intel OpenVINO без залежностей від вихідного фреймворку, а також проведення порівняльного бенчмаркінгу продуктивності на CPU.

---

## Інструкція із запуску

### 1. Експорт моделі в ONNX та перевірка валідності
Експорт чекпоінту `models/best_cnn_model.pt` у файл `models/simple_cnn.onnx` з динамічною віссю батчу:
```powershell
python -m lab04_deployment.export_onnx
```
Скрипт перевіряє валідність графа через `onnx.checker` та обчислює максимальну похибку відхилення логітів проти PyTorch (менше $4.2 \times 10^{-7}$).

### 2. Запуск автономного інференсу ONNX Runtime
Класифікація вхідного зображення засобами OpenCV та ONNX Runtime без імпорту PyTorch:
```powershell
python lab04_deployment/onnx_inference.py data/dataset/drone/drone_001.jpg
```

### 3. Запуск автономного інференсу Intel OpenVINO
Компіляція моделі під інструкції процесора та прямий прохід в OpenVINO:
```powershell
python lab04_deployment/openvino_inference.py data/dataset/pedestrian/pedestrian_001.jpg
```

### 4. Запуск порівняльного бенчмаркінгу
Вимірювання затримок для одиночного інференсу ($B=1$) та пакетної обробки ($B=8$) за 150 ітераціями після 20 викликів warm-up:
```powershell
python -m lab04_deployment.benchmark
```

## Результати порівняльного бенчмаркінгу (CPU)
| Показник | PyTorch (CPU) | ONNX Runtime (CPU) | Intel OpenVINO (CPU) |
| :--- | :---: | :---: | :---: |
| **Затримка інференсу B=1** | 1.21 ± 0.17 мс | **0.29 ± 0.10 мс** | **0.27 ± 0.15 мс** |
| **Медіанна затримка B=1** | 1.17 мс | 0.26 мс | **0.25 мс** |
| **95-й перцентиль P95 B=1** | 1.56 мс | **0.48 мс** | 0.50 мс |
| **Пропускна здатність B=1 (FPS)** | 827.5 кадр/с | 3393.7 кадр/с | **3758.0 кадр/с** |
| **Затримка батчу B=8** | 6.24 мс | 1.77 мс | **0.94 мс** |
| **Пакетний Throughput B=8** | 1282.0 img/s | 4508.8 img/s | **8499.8 img/s** |
| **Розмір моделі на диску** | 4.10 МБ | **1.36 МБ** | **1.36 МБ** |
| **Прискорення інференсу (B=1)** | 1.00x | **4.17x** | **4.48x** |
| **Прискорення пакета (B=8)** | 1.00x | 3.52x | **6.63x** |

### Ключові висновки:
- **Оптимізація графа**: ONNX Runtime та OpenVINO зменшують затримку відгуку в 4.2–4.5 раза завдяки злиттю операцій (Conv+BatchNorm+ReLU) та відсутності накладних витрат Python-інтерпретатора.
- **Пакетна векторизація**: OpenVINO демонструє найвищу пакетну продуктивність (майже 8500 img/s) за рахунок використання AVX2/AVX-512 інструкцій процесора.
- **Чисельна стабільність**: максимальне відхилення логітів склало $4.17 \times 10^{-7}$, що гарантує збереження 100% точності класифікації.
