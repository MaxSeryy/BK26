# Лабораторна робота №5: Профілювання та апаратна оптимізація інференсу

## Мета
Апаратна оптимізація моделі за допомогою OpenVINO Toolkit, профілювання затримок та квантування для прискорення виконання на CPU / iGPU / NPU.

## Заплановані завдання
1. Конвертація моделі в OpenVINO Intermediate Representation (IR).
2. Пост-тренувальне квантування (INT8) за допомогою NNCF.
3. Профілювання пропускної здатності (throughput, FPS) та латентності (latency).
4. Порівняльний аналіз швидкодії до та після оптимізації.
