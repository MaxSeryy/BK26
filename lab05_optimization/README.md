# Лабораторна робота №5: Квантування, профілювання та інтеграція AI-системи

## Мета роботи
Оптимізувати модель нейронної мережі для швидкого інференсу методом квантування (INT8), виконати детальне профілювання інтегрованого AI-конвеєра комп'ютерного зору, виявити вузькі місця системи та обґрунтувати інженерний вибір конфігурації розгортання з урахуванням точності, латентності, пропускної здатності та апаратних обмежень.

## Індивідуальний варіант
- **Варіант:** 13
- **Класи об'єктів (3 класи):** `car`, `drone`, `pedestrian`
- **Вхідний чекпоінт:** `models/best_cnn_model.pt` / `models/simple_cnn.onnx` (FP32, 1.36 MB)
- **Цільова квантована модель:** `models/simple_cnn_int8.onnx` (INT8, 0.35 MB)

---

## Структура модулів лабораторної роботи
1. `quantize.py` — статичне пост-тренувальне квантування (Static PTQ INT8) засобами ONNX Runtime з калібрувальним `CalibrationDataReader` (60 зразків з train), валідація графа `onnx.checker` та оцінка деградації точності на 45 тестових зображеннях.
2. `pipeline.py` — інтегрований end-to-end конвеєр (декодування кадру $\rightarrow$ preprocessing $\rightarrow$ INT8 inference $\rightarrow$ postprocessing $\rightarrow$ візуалізація HUD). Профілювання таймінгу кожного етапу з використанням високоточних лічильників `time.perf_counter` та локалізація вузького місця (bottleneck).
3. `benchmark.py` — комплексний порівняльний бенчмарк runtime-середовищ та рівнів точності (PyTorch CPU, ONNX Runtime FP32/INT8 CPU, OpenVINO FP32/INT8 CPU), вимірювання затримок B=1, пропускної здатності B=8 (FPS), споживання RAM (RSS) та діагностика доступних прискорювачів (CPU, dGPU RTX 4050, NPU).
4. `opt_flowchart.drawio` — детальна схема конвеєра оптимізації та профілювання у форматі Draw.io.
5. `figures/` — згенеровані графіки, анотований кадр та експортована діаграма:
   - `opt_flowchart.png` — архітектурна схема конвеєра оптимізації;
   - `quantization_evaluation.png` — порівняння розміру, точності та затримки FP32 vs INT8;
   - `pipeline_annotated.png` — зразок вихідного кадру конвеєра з оверлеєм затримок та класифікації;
   - `pipeline_breakdown.png` — декомпозиція часових витрат по етапах та частки у загальному часі;
   - `optimization_benchmark.png` — підсумковий бенчмарк затримок, пропускної здатності та розміру моделей.

## Інструкція із запуску

Усі команди виконуються в активованому віртуальному оточенні `venv`:

```powershell
# 1. Пост-тренувальне квантування INT8 та оцінка точності
python lab05_optimization/quantize.py

# 2. Профілювання інтегрованого AI-конвеєра та аналіз вузького місця
python lab05_optimization/pipeline.py

# 3. Комплексний бенчмарк середовищ виконання та апаратних платформ
python lab05_optimization/benchmark.py
```

## Основні результати

### 1. Результати квантування (FP32 проти INT8)
- **Розмір файлу:** зменшено з 1.360 MB до 0.352 MB (коефіцієнт стиснення **3.87x**, економія 74.1% пам'яті).
- **Точність на тестовій вибірці:** 100.0% для FP32 та 100.0% для INT8 (дельта точності: **0.0%**, нульова деградація).
- **F1-Macro:** 1.000 для обох моделей.

### 2. Декомпозиція конвеєра та локалізація вузького місця
- **Acquisition (декодування з диска):** 2.24 мс (67.4% часу конвеєра) — **ВУЗЬКЕ МІСЦЕ**.
- **Preprocessing (OpenCV resize, BGR->RGB, нормування):** 0.25 мс (7.4%).
- **INT8 Inference (ONNX Runtime CPU):** 0.30 мс (9.1%).
- **Postprocessing (Softmax, Top-1):** 0.05 мс (1.4%).
- **HUD Rendering (накладання графіки):** 0.44 мс (13.2%).
- **Сумарний час конвеєра:** 3.32 мс (**301 FPS**).

### 3. Порівняльний бенчмарк (Inference Engine)
| Середовище / Конфігурація | Точність | Затримка B=1 (мс) | Throughput B=8 (FPS) | Розмір (MB) | RAM RSS (MB) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| PyTorch (CPU) | FP32 | 1.158 | 1 373.3 | 4.095 | 275.9 |
| ONNX Runtime (CPU) | FP32 | 0.344 | 3 939.9 | 1.360 | 299.9 |
| **ONNX Runtime (CPU)** | **INT8** | **0.188** | **5 895.1** | **0.352** | **290.4** |
| OpenVINO (CPU) | FP32 | 0.212 | 9 878.2 | 1.360 | 313.9 |
| **OpenVINO (CPU)** | **INT8** | **0.261** | **13 062.1** | **0.352** | **315.2** |

### 4. Апаратні обмеження
- **CPU:** AMD Ryzen 5 7640HS (використовує набір векторних інструкцій AVX-512 / VNNI для апаратного прискорення INT8).
- **dGPU:** NVIDIA GeForce RTX 4050 Laptop GPU (плагін OpenVINO Intel GPU не підтримує виконання OpenCL на неінтелівських відеокартах, помилка `CL_BUILD_PROGRAM_FAILURE`).
- **NPU:** Відсутній в апаратній конфігурації робочої станції.
