# Лабораторна робота №1: Підготовка та обробка даних для систем штучного інтелекту

## Мета роботи
Набути практичних навичок завантаження, аналізу, очищення, перетворення та підготовки набору зображень для подальшого навчання моделі машинного або глибинного навчання засобами Python, NumPy та OpenCV.

## Структура модуля
- `generate_dataset.py` — процедурний синтез датасету для 3 класів (drone, car, pedestrian) з контрольованим шумом, різною роздільною здатністю та 2 дефектними файлами.
- `pipeline.py` — наскрізний конвеєр перевірки файлів, конвертації BGR $\rightarrow$ RGB, letterbox-масштабування (224×224), нормалізації, стратифікації (seed=13) та 4 видів аугментації.
- `data_loader.py` — автономний клас `VisionDatasetLoader` для пакетного завантаження тензорів (для використання в ЛР №2).
- `draw_flowchart.py` — скрипт генерації блок-схеми процесу обробки.
- `pipeline_flowchart.drawio` — вихідний макет блок-схеми для редактора Draw.io.
- `figures/` — графічні матеріали для звіту (гістограми розподілу класів, розмірів зображень, зразки класів та аугментацій).

## Інструкція із запуску
```bash
# 1. Генерація вибірки зображень
python lab01_data/generate_dataset.py

# 2. Обробка та аналіз датасету
python lab01_data/pipeline.py

# 3. Тестування завантажувача
python lab01_data/data_loader.py
```
